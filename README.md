# Evolution

AI 作業系統框架 — 多節點協作、意圖驅動的軟體生成系統。

## 分支結構

| Branch | 內容 |
|--------|------|
| `os` | 作業系統核心 — Planner、Kernel、Executor、Skill Registry |
| `main` | 整合版（規劃中）|

## 目前進度

- `os` branch：已上線，包含完整的 Planner CLI、LLM 整合、安裝腳本
- `main`：等待各模組整合完成後，作為 stable release branch

## 相關模組（未来）

- `researching` — 推理引擎
- `compiler` — Evolution Compiler
