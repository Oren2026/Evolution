# v0.7 — Demo：目錄分析器

## v0.7 目標

用真實技能展示 EvolutionOS 的完整執行鏈。

## 情境

```
使用者：「幫我分析 ~/Desktop/funnytest/evolution_os 這個專案結構」

Execution chain:
  analyze_project (leaf)
    → read_directory
      → analyze_file_stats
        → summarize_project (root)
```

## 需要實現的真實技能

### 1. FileSystemSkill
- `read_dir(path)` → 回傳目錄內容（檔案/資料夾清單）
- 使用 `std::fs::read_dir`

### 2. FileStatsSkill  
- `analyze_stats(paths)` → 每個檔案的行數、副檔名統計
- 使用 `std::fs::metadata` + `std::fs::read_to_string` 算行數

### 3. ProjectAnalyzerSkill
- `summarize(stats)` → 專案總結（模組數、測試數、程式碼行數）

## 執行流程

```
os.execute("analyze_project", "~/Desktop/funnytest/evolution_os")
  → Executor.execute_or_discover(graph, "analyze_project")
    → BFS探索：analyze_project → read_directory → analyze_file_stats → summarize_project
    → 反轉：summarize_project(根) → analyze_file_stats → read_directory → analyze_project(葉)
    → 按序執行每個節點，Context一路往下傳
  → 最終輸出：專案摘要報告
```
