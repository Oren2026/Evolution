1. `Node` trait 定義（所有節點的共同介面）
2. `MemoryGraph` 資料結構（節點儲存 + 查詢）
3. `ChainDiscovery` 基本探索雛形
4. 單元測試覆蓋

## Node Trait 設計

```rust
pub trait Node {
    type Output;
    
    fn id(&self) -> &str;
    fn dependencies(&self) -> Vec<&str>;  // 這個節點依賴哪些其他節點
    fn execute(&self, ctx: &Context) -> Self::Output;
    fn category(&self) -> NodeCategory;
}

#[derive(Debug, Clone, Copy, PartialEq)]
pub enum NodeCategory {
    Skill,    // 技能節點
    Context,  // 上下文節點
    Chain,    // 呼叫鏈節點
}
```

## MemoryGraph 設計

```rust
pub struct MemoryGraph {
    nodes: HashMap<String, Box<dyn Node>>,
    chains: HashMap<String, ChainNode>,  // 已驗證的呼叫鏈
}

impl MemoryGraph {
    pub fn add_node(&mut self, node: Box<dyn Node>);
    pub fn find_chain(&self, leaf_id: &str) -> Option<&ChainNode>;
    pub fn register_chain(&mut self, chain: ChainNode);
    pub fn query(&self, key: &str) -> Vec<&dyn Node>;
}
```
