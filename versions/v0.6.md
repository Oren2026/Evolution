# v0.6 — 完整整合（Executor + Model + Storage）

## v0.6 目標

將 v0.1-v0.5 的所有模組整合成一個統一的 EvolutionOS runtime。

## 設計

### EvolutionOS — 統一入口

```rust
pub struct EvolutionOS {
    graph: MemoryGraph,
    executor: Executor,
    model_dispatcher: Box<dyn ModelDispatcher>,
    storage: JsonStorage,
    auto_persist: bool,
    persist_threshold: u32,
}

impl EvolutionOS {
    pub fn new(dispatcher: Box<dyn ModelDispatcher>, storage: JsonStorage) -> Self;
    pub fn load_or_create(dispatcher: Box<dyn ModelDispatcher>, storage: JsonStorage) -> Result<Self, Error>;
    pub fn execute(&mut self, leaf_id: &str, input: &str) -> Result<NodeResult, Error>;
    pub fn persist(&self) -> Result<(), StorageError>;
}
```

### MemoryGraph ↔ PersistedGraph 轉換

`MemoryGraph.to_persisted()` 和 `MemoryGraph::from_persisted()` 讓圖形可以序列化/反序列化。

### 自動快照

- 每 N 次 execute() 自動寫入磁碟（計數器）
- 手動 `os.persist()` 立即寫入

### 健康檢查

```rust
os.health_check() 
// → { graph_nodes, stored_chains, model_available, last_persisted }
```

## 預期產出

- `src/evolution_os.rs` — EvolutionOS 主結構
- `MemoryGraph.to_persisted()` / `from_persisted()`
- 新增測試 ~5 個

## 測試案例

1. `EvolutionOS::new()` → 初始空 graph
2. `load_or_create()` → 從磁碟還原 + 新建
3. `execute()` → 執行鏈並更新 graph
4. `persist()` → 寫入磁碟並可讀回
5. 自動快照觸發（每 N 次）
