## 設計

### Executor

```rust
impl Executor {
    /// 執行葉節點的呼叫鏈
    /// 1. ChainDiscovery 取得完整路徑（從葉往上）
    /// 2. 反轉路徑（變成從根到葉的順序）
    /// 3. 按順序執行每個節點，上下文一路往下傳
    pub fn execute(&self, graph: &mut MemoryGraph, leaf_id: &str) -> NodeResult {
        let discovery = ChainDiscovery::new();
        let path = discovery.discover(graph, leaf_id)?;
        
        // 反轉：從根到葉
        let forward_path: Vec<&str> = path.iter().rev().map(|s| s.as_str()).collect();
        
        let mut ctx = Context::new(leaf_id);
        let mut last_result = NodeResult::ok("");
        
        for node_id in forward_path {
            if let Some(node) = graph.get_node(node_id) {
                last_result = node.execute(&mut ctx);
                if !last_result.success {
                    break; // 失敗就停止
                }
            }
        }
        
        last_result
    }
}
```

### SkillNode 實作

讓具體的技能節點（如 `HtmlSkill`、`CssSkill`）實作 `Skill` trait，並接入 `Executor`。
