# v0.4 — ModelDispatcher（AI syscall 介面）

## v0.4 目標

讓 Evolution OS 可以真正呼叫 LLM，將 model call 包裝成「系統呼叫」。

## 設計

### 分層架構

```
SkillNode（業務邏輯）
    ↓
Executor（執行協調）
    ↓
ModelDispatcher（AI syscall 介面）← v0.4 焦點
    ↓
ModelBackend（Ollama / OpenAI）
```

### ModelDispatcher Trait

```rust
pub trait ModelDispatcher: Send + Sync {
    fn dispatch(&self, req: ModelRequest) -> Result<ModelResponse, DispatchError>;
    fn available_models(&self) -> Vec<String>;
}
```

### ModelRequest / ModelResponse

```rust
pub struct ModelRequest {
    pub model: String,
    pub prompt: String,
    pub system_prompt: Option<String>,
    pub temperature: f32,
    pub max_tokens: Option<u32>,
}

pub struct ModelResponse {
    pub content: String,
    pub model: String,
    pub tokens_used: u32,
}
```

### DispatchError

- `ModelNotFound` — 模型不存在
- `Timeout` — 請求超時
- `RateLimited` — 速率限制
- `BackendError(String)` — 底層錯誤

### OllamaBackend

- 實作 `ModelDispatcher`
- 連接 `http://localhost:11434`
- `/api/generate` endpoint
