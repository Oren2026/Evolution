# v0.5 — 記憶圖持久化

## v0.5 目標

讓 MemoryGraph 可以持久化儲存（序列化到磁碟，重啟後可還原）。

## 設計

### Storage trait

```rust
pub trait Storage: Send + Sync {
    fn save(&self, graph: &MemoryGraph) -> Result<(), StorageError>;
    fn load(&self) -> Result<MemoryGraph, StorageError>;
}
```

### JsonStorage

- 使用 serde_json 將 MemoryGraph 序列化成 `.json` 檔案
- 位置：`~/.evolution_os/graph.json`（可設定）

### 快照策略

- 每 N 次操作自動 snapshot（計數器）
- 手動 `graph.persist()` 立即寫入
- `graph.load()` 從磁碟還原

## 測試

- 寫入 → 刪除 → 讀回，確認資料一致
- 並發安全測試
- 損壞檔案處理
