Evolution OS

意圖驅動的多平台軟體編譯框架

Rust Stable MIT License

概述

Evolution OS 是一個意圖驅動（Intent-driven）的軟體編譯框架，設計用於處理跨平台專案的自動化建置、分析與優化。核心思想是讓系統「理解你想要什麼，而不是你命令它做什麼」。

通過自然語言輸入，系統自動推理模組依賴關係、重構優先級、平台兼容性，輸出可直接部署的編譯產物。

Layer 0→3 架構

系統採用四層漸進式決策架構：

Layer 0

意圖層 Intent

解析使用者輸入意圖，轉換為系統內部可處理的任務樹。

Layer 1

分類層 Categorization

將意圖分類為編譯、重構、分析等類別，選擇對應的處理管線。

Layer 2

路由層 Routing

分散式節點路由：各模組在本地做決策，不依賴中央強節點。

Layer 3

執行層 Execution

實際執行編譯、建置分析、產出最終結果。

Core Modules

kernel Runtime 核心與執行引擎
compiler 多平台編譯器前端
executor 任務執行器與工作緒池
planner 任務規劃與依賴解析
node 節點暫存器與工廠
chain 連鎖發現與拓撲排序
graph 依賴圖建構與查詢
system 系統安裝與環境偵測
model LLM 後端整合
registry 全域節點註冊表

System Processes

init 初始化系統與節點圖
build 觸發多平台建置流程
analyze 專案結構分析
replan 動態重規劃執行策略
install 系統級工具鏈安裝
report 建置報告生成

CLI Commands

Command說明
evolution analyze分析專案結構並生成依賴圖
evolution build觸發多平台編譯流程
evolution plan顯示執行計畫而不實際執行
evolution init初始化新專案或現有專案
planner_cli manifest生成 Planner 意圖描述
analyze_project分析目錄結構與模組關係
demo_framework展示框架核心功能範例
integration_demo跨模組整合測試演示

建置方式

cargo build --release
cargo test --no-default-features

需要 Rust 1.70+。建議使用 --no-default-features 避免編譯期間的 LLM 後端依賴（可在 runtime 透過設定啟用）。

安裝說明

1

Clone 本專案

git clone https://github.com/Oren2026/Evolution.git

2

編譯

cargo build --release

3

執行

產物位於 target/release/ 目錄下，包含 evolution 主程式及多個 CLI 工具。
