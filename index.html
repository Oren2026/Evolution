Evolution OS

意圖驅動的多平台軟體編譯框架

Rust v0.3.1 MIT License

概述

Evolution OS 是一個意圖驅動（Intent-driven）的軟體工程 Framework。核心問題：如何讓 AI 在開始實作之前，先理解任務的複雜度，自動決定分工策略，並在過程中保持決策的可解釋性？

設計原則：問題未確認不實作、資訊重構複雜度驅動分工、邏輯上的遞迴（Planner 輸出優化下次輸入結構）、可驗證的決策。

Layer 0→3 漸進式決策架構

Layer 0

意圖層 Intent

解析自然語言輸入，提取領域標籤與複雜度因子。

Layer 1

複雜度分析 Categorization

計算 branches、diversity、complexity 三維指標。

Layer 2

分工決策 Routing

根據複雜度動態選擇 Solo（單節點）或 Fork（多節點分工）。

Layer 3

執行層 Execution

PlannerManifest 驅動下游 Compiler / Executor。

Core Modules（src/）

kernel/ OS 核心：Process / Mailbox / Scheduler / ProcessTable / SysCall / SystemProcess
planner/ 任務規劃：stages.rs / decision.rs / manifest.rs
runtime/ 依賴圖執行引擎（GraphExecutor）
node/ 節點抽象：SkillNode / DynSkillNode / MemoryGraph / Registry
model/ AI 後端派遣（Ollama 支援）
storage/ JSON 持久化
chain/ 呼叫鏈探索（葉→根 BFS）
skill/ 技能實現（filesystem.rs 等）
compiler/ 多平台編譯器前端
commands/ CLI 子命令：analyze / new_project / list_skills / shell

Windows 使用方式（PowerShell）

基本指令

# 先進入下載資料夾（用 cmd 或 PowerShell）
cd .\Downloads

# 執行 Evolution
.\evolution.exe analyze "幫我建一個庫存管理系統"
.\evolution.exe --help
⚠️ 必須加上 .\ 前綴，PowerShell 預設不從目前目錄載入命令

如何快速開啟命令視窗

# 方法 1：在資料夾網址列輸入 cmd（最快）
# 來到 evolution.exe 所在資料夾
# 點擊網址列，輸入 cmd，按 Enter
# 就會開啟一個已定位在該資料夾的命令視窗

# 方法 2：在資料夾空白處 Shift+右鍵 →「在此處開啟 PowerShell 視窗」

# 方法 3：在檔案總管網址列輸入 powershell，按 Enter

建立捷徑方便日後使用

# 1. 對 evolution.exe 按右鍵 →「傳送到」→ 「桌面建立捷徑」
# 2. 對桌面捷徑按右鍵 → 內容
# 3. 在「捷徑」頁面，「目標」改為：
#    cmd /k evolution.exe
# 4. 以後點捷徑就會開一個命令視窗
💡 捷徑的「起始位置」也要設為 evolution.exe 所在的資料夾

常見用法

# 分析任務複雜度（主要功能）
.\evolution.exe analyze "建立兩個資料夾"
.\evolution.exe analyze "幫我建一個有前端、後端、資料庫的系統"

# 列出可用功能
.\evolution.exe --help

# 建立新專案
.\evolution.exe new my-project

# 互動模式
.\evolution.exe shell

macOS / Linux 使用方式（Terminal）

基本指令

# Clone 並進入目錄
git clone https://github.com/Oren2026/Evolution.git
cd ~/Desktop/Evolution-new/

# 執行（需要先建置）
cargo build
cargo run --bin planner_cli -- "幫我建一個庫存系統"
cargo run --bin planner_cli -- "寫一個計數器網頁"

完整建置與測試

cargo build --release
cargo test
ls target/release/

分工決策閾值

指標Solo 條件Fork 條件
reasoning_branches≤ 2≥ 3
domain_diversity≤ 1≥ 2
context_complexity≤ 0.6> 0.6

三者之一滿足就觸發 Fork Mode。
