Evolution OS

意圖驅動的多平台軟體編譯框架

Rust v0.3.1 MIT License

概述

Evolution OS 是一個意圖驅動（Intent-driven）的軟體工程 Framework。核心問題：如何讓 AI 在開始實作之前，先理解任務的複雜度，自動決定分工策略，並在過程中保持決策的可解釋性？

設計原則：問題未確認不實作、資訊重構複雜度驅動分工、邏輯上的遞迴（Planner 輸出優化下次輸入結構）、可驗證的決策。

Layer 0→3 漸進式決策架構

Layer 0

意圖層 Intent

解析自然語言輸入，提取領域標籤與複雜度因子。

Layer 1

複雜度分析 Categorization

計算 branches、diversity、complexity 三維指標。

Layer 2

分工決策 Routing

根據複雜度動態選擇 Solo（單節點）或 Fork（多節點分工）。

Layer 3

執行層 Execution

PlannerManifest 驅動下游 Compiler / Executor。

Core Modules（src/）

kernel/ OS 核心：Process / Mailbox / Scheduler / ProcessTable / SysCall / SystemProcess
planner/ 任務規劃：stages.rs / decision.rs / manifest.rs
runtime/ 依賴圖執行引擎（GraphExecutor）
node/ 節點抽象：SkillNode / DynSkillNode / MemoryGraph / Registry
model/ AI 後端派遣（Ollama 支援）
storage/ JSON 持久化
chain/ 呼叫鏈探索（葉→根 BFS）
skill/ 技能實現（filesystem.rs 等）
compiler/ 多平台編譯器前端
commands/ CLI 子命令：analyze / new_project / list_skills / shell

CLI 使用方式

1. Planner CLI — 任務分工分析（主力工具）

# 簡單任務 → Solo Mode
cargo run --bin planner_cli -- "寫一個計數器網頁"

# 複雜任務 → Fork Mode
cargo run --bin planner_cli -- "幫我建一個庫存管理系統，要有前端、後端、資料庫、登入功能"

# 互動模式（多行輸入）
cargo run --bin planner_cli -- --interactive
🔀 分工模式：Solo（單一節點） 理由：branches=1, diversity=1, complexity=0.05 → Solo（單一節點） 預估節點數：1 📋 需求項目（1 項） ❓ 待確認問題（2 項）

2. analyze_project — 目錄結構分析

# 分析任意目錄
cargo run --bin analyze_project -- ~/Desktop/Evolution-new/src
⚠️ 目前輸出較基本，適合作為 Framework 展示

3. 一鍵執行（需先 build）

# 從 repo 根目錄執行
cd ~/Desktop/Evolution-new/

# 完整 build
cargo build --release

# 測試（127 tests: 106 unit + 6 integration + kernel 11 + runtime 7）
cargo test

4. 常用组合指令

# 快速試用（不需 build release）
cargo build
cargo run --bin planner_cli -- "幫我建一個部落格系統"

# 只看分工決策，不實際執行
cargo run --bin planner_cli -- "我要電商平台"

# 看完整 JSON output（pipe to jq）
cargo run --bin planner_cli -- "庫存系統" 2>/dev/null | grep -A 100 '"dispatch"'

分工決策閾值

指標Solo 條件Fork 條件
reasoning_branches≤ 2≥ 3
domain_diversity≤ 1≥ 2
context_complexity≤ 0.6> 0.6

三者之一滿足就觸發 Fork Mode。

安裝與建置

1

Clone 本專案

git clone https://github.com/Oren2026/Evolution.git
cd ~/Desktop/Evolution-new/

2

建置

cargo build --release

建置產物：target/release/evolution、target/release/planner_cli、target/release/analyze_project

3

執行 Planner

cargo run --bin planner_cli -- "你的任務描述"
